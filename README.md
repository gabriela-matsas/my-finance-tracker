## Sobre

App de controle financeiro pessoal feito em HTML, CSS e JavaScript puro, sem
dependências externas. Os dados ficam salvos no navegador (localStorage).

## Funcionalidades

- Cadastro de receitas e despesas por categoria
- Filtro de transações por mês, com navegação entre meses
- Orçamento mensal por categoria, com aviso visual quando o limite é ultrapassado
- Gráfico de despesas por categoria
- Calculadora rápida embutida
- Modo claro/escuro
